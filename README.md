### 🚀 About Me

I'm a Cloud & Infrastructure Engineer with hands-on experience running **AWS infrastructure**, **Microsoft 365 / Entra ID environments**, and building **CI/CD pipelines, Docker-based deployments, and monitoring stacks**. I care about systems that are observable, secure, and boring to operate — in a good way.

- 🔭 Currently building an end-to-end **cloud deployment & observability platform** (GitHub Actions → Docker → EC2 → Nginx → Prometheus/Grafana)
- 🌱 Currently learning **Terraform** to bring Infrastructure as Code into that pipeline
- 💬 Ask me about **AWS, Linux troubleshooting, Docker, CI/CD, or Microsoft 365 administration**
- ⚡ Fun fact: I'd rather fix the alert than silence it
